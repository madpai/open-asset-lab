## Practical sequence

1. Document current OALMAP/OALASSET field provenance, IDs, and loader limits; add synthetic validation fixtures for missing/duplicate IDs and dependencies.
2. Prove a second source family (original glTF) before generalizing Mesh/Material/Skeleton IRs. This follows the existing vision rather than creating speculative abstractions.
3. Co-design one generic world-event slice with MegaMod and compile a synthetic button/door/trigger map. Check referential integrity and report unsupported source behavior.
4. Prototype immutable definition registry and one host-authoritative scripted ability only after the runtime boundary and script API are measured.
5. Delay container redesign, cross-package patching, and structural analysis until real content requires them.

**Publication boundary:** an importer being technically feasible says nothing about permission to redistribute its input or output. Keep private game data out of both repositories, as [AGENTS.md](../AGENTS.md) requires.
