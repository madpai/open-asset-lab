# Navigation: Recast build, Detour query

## Observed system

**VERIFIED:** [Recast's official overview](https://github.com/recastnavigation/recastnavigation) separates voxelization, walkability filtering, region partitioning and polygon construction from Detour's runtime loading and path queries. It offers single and tiled meshes, DetourCrowd, tile cache and DebugUtils. A mesh is a traversable *surface for an agent center*, not a collision solver. [Godot's navigation guide](https://docs.godotengine.org/en/4.2/tutorials/navigation/navigation_using_navigationmeshes.html) makes the build parameters explicit: radius erodes boundaries; height, climb and slope exclude spans. A single bake does not necessarily fit a croucher, giant or flyer.

**VERIFIED:** Detour's [query API](https://recastnav.com/classdtNavMeshQuery) finds nearest polygons, polygon corridors, straight paths and local surface motion using a query filter. Its [off-mesh connection](https://recastnav.com/structdtOffMeshConnection.html) stores endpoints, radius, link metadata and a caller assigned ID. [DebugUtils](https://recastnav.com/DetourDebugDraw_8h.html) can draw tiles, connections, polygons and query nodes. Tiled builds support localized updates and streaming, with higher packaging and validation complexity. Crowd movement is a separate optional module; it does not magically give doors, elevators or tactical behavior. Godot [warns](https://docs.godotengine.org/en/4.0/tutorials/navigation/navigation_using_navigationagents.html) that local avoidance is separate from navmesh and physics, and may deadlock at narrow passages.

## Proposed OAL → package → host contract

1. **OAL offline:** gather normalized *collision* geometry and authored traversal links; apply a declared agent profile and canonical unit/axis conversion; bake and preview polygons, islands, slope exclusions, clearance, links and unreachable starts; report source geometry/hash, build parameters, Recast version, missing links and coverage. Prefer simplified collision over render meshes. Rebuild deterministically for each profile actually needed, not every imagined NPC size.
2. **Package proposal:** `facility:navmesh/main` is a plausible typed resource, referenced by the world and tied to its geometry/world key. It would have a versioned OAL wrapper with coordinate convention, profile, bounds, build recipe/hash, tile directory, bounded sizes and off-mesh link IDs. **SPECULATIVE:** whether one navmesh is a resource per world or one resource per profile needs real fixtures. Never use a path as identity; follow X4's `namespace:type/name` and declared imports. Do not register the type yet.
3. **Host runtime:** load validated tiles; map start/goal to polygons; query a filtered corridor and corners; follow it through existing movement/collision; invalidate or repair on obstruction; own all traversals and action requests. Agent position and outcome replicate, not the corridor. A query failure must be visible and recoverable.

## Binary and dynamic hazards

Detour tile bytes and `dtPolyRef` are implementation details. **Recommendation:** avoid promising cross-version or cross-endian stability of raw `dtCreateNavMeshData` output. Put a version/endianness/coordinate contract around any tile payload, test x86-64 and Android ARM64 load, validate offsets/counts, and require a compiler/runtime compatibility check. Serialize link identity separately from transient polygon references. World transforms should be baked into world space; if tiled geometry moves, its navmesh must be rebuilt or given an explicit traversal affordance. An opening door changes traversal *eligibility* and collision; it need not force a full tile rebuild. A lift/teleport/jump link needs eligibility, ownership, animation and completion, not merely a graph edge. Tile-cache obstacles merit later measurement; rebuild cost and link preservation need fixtures before adoption.

**First experiment:** bake one synthetic two-room original map with a door, two agent radii and a disconnected upper platform; prove identical OAL output hashes, host path/no-path results, link gating, late join behavior, Android loading and polygon debug view. Keep the existing grid for legacy worlds until parity is demonstrated. Recast/Detour's [zlib license](https://github.com/recastnavigation/recastnavigation/blob/main/License.txt) permits integration with notice preservation.
